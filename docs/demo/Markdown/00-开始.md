# Markdown 形态测试集

每篇集中测一类语法，开头的“预期”说明应该看到什么。逐篇打开，先看排版，再把光标移进每个块，确认源码原样展开、移出后恢复排版。

通用检查：

- 拖窄侧栏或缩小终端，看折行和缩进是否正确。
- 在块内输入、删除、撤销，确认源码没有被改写。
- 离开文件后用 `git diff docs/demo` 确认只有你主动改的内容。
