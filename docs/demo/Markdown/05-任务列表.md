# 任务列表

预期：`[ ]` 与 `[x]` 显示为未完成/已完成标记；大写 `[X]` 也算完成；格式不对的方括号保持字面。

## 基本

- [ ] 未完成
- [x] 已完成
- [X] 大写 X 也算完成

## 嵌套任务

- [ ] 发布 0.2
  - [x] 修复冲突卡死
  - [x] 草稿故障不阻塞保存
  - [ ] 补充 Markdown 测试集
    - [ ] 表格
    - [x] 图片

## 有序任务

1. [x] 第一步
2. [ ] 第二步
3. [ ] 第三步

## 带格式的任务

- [ ] 阅读 [CommonMark 规范](https://spec.commonmark.org)
- [x] ~~已经放弃的想法~~
- [ ] 包含 `代码`、**粗体** 和 [[目标笔记]]
- [ ] 很长的任务描述，用来检查折行后续行是否对齐到任务文字，而不是对齐到方框或列表标记。Long task text wraps here.

## 不是任务

- [] 方括号里没有空格
- [ ]没有空格紧跟文字
- [-] 横线不是有效状态
- [ x ] 多了空格
[ ] 不在列表里

* [ ] 星号列表的任务
+ [x] 加号列表的任务
