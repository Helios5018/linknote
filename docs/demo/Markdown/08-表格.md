# 表格

预期：表格带外框和行间横线；列宽按字素显示宽度分配，中文与 emoji 对齐；列太多时纵向按记录排版；进入后整块显示源码并用虚拟空白对齐，源码本身不被重写。

## 基本

| 操作 | 快捷键 |
| --- | --- |
| 新建笔记 | 左栏 a |
| 全文搜索 | Ctrl+P 后 Tab |

## 对齐

| 左对齐 | 居中 | 右对齐 | 默认 |
| :--- | :---: | ---: | --- |
| a | b | c | d |
| 很长的左对齐内容 | 居中内容 | 12,345.67 | x |
| 1 | 2 | 3 | 4 |
