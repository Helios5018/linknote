# 脚注

预期：脚注引用显示为上标样式的编号或名称；脚注定义作为独立块显示；未定义的脚注保持字面。修改定义后引用处同步更新（文档级上下文变化）。

## 基本

LinkNote 使用 pulldown-cmark 解析[^1]，界面基于 Ratatui[^ratatui]。

[^1]: pulldown-cmark 0.13。
[^ratatui]: https://ratatui.rs

## 同一个脚注引用多次

第一次[^同一个]，第二次[^同一个]。

[^同一个]: 被引用两次的脚注。

## 定义在引用之前

[^先定义]: 定义写在前面也可以。

这里引用前面定义的脚注[^先定义]。

## 多段脚注

正文[^多段]。

[^多段]: 脚注第一段。

    缩进四格的第二段属于同一个脚注。

    ```
    脚注里的代码
    ```

## 脚注里的样式

带格式的脚注[^样式]。

[^样式]: **粗体**、`代码`、[链接](https://example.com) 和 [[目标笔记]]。

## 未定义

引用了不存在的脚注[^没有定义]。

## 不是脚注

[^ 中间有空格]

`[^代码里的]`
