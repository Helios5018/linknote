# 行内样式

预期：各样式在排版时去掉标记符号；光标所在段显示原始符号且可直接编辑。转义和代码内的符号保持字面。

## 基本样式

**粗体** 和 __下划线粗体__

*斜体* 和 _下划线斜体_

***粗斜体*** 和 **_混合写法_**

~~删除线~~ 和 ~单波浪线~

`行内代码` 和 ``双反引号代码``

## 嵌套

**粗体里有 *斜体* 和 `代码`**

*斜体里有 **粗体***

~~删除线里有 **粗体** 和 [链接](https://example.com)~~

[**粗体链接**](https://example.com) 与 [`代码链接`](https://example.com)

## 词内与下划线

un*frigging*believable 中星号在词内生效。

snake_case_variable_name 中下划线不生效。

2*3*4 与 a * b * c 的星号边界。

## 中文标点加粗

**注意：**这里粗体紧跟中文，CommonMark 不认，LinkNote 兼容规则应加粗。

**“引号”**包在粗体里。

前面是中文**粗体，**后面也是中文。

**提示**：标点放在粗体外面。

## 转义

\*不是斜体\*、\_不是斜体\_、\`不是代码\`

\[不是链接\](https://example.com)

\\ 单个反斜杠，\# 不是标题，\- 不是列表

## 代码里的反引号

`` `code` `` 包含反引号。

``` `` ``` 包含两个反引号。

`**代码里的星号不加粗**`

## 行内 HTML

<kbd>Ctrl</kbd>+<kbd>S</kbd> 立即保存。

H<sub>2</sub>O 与 E=mc<sup>2</sup>

<mark>高亮</mark>、<u>下划线</u>、<span style="color:red">红字</span>

## 空与孤立的标记

**** 四个星号

** ** 中间只有空格

`` 两个反引号

* 单独一个星号后面跟空格是列表，不是样式
