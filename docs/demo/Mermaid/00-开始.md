# Mermaid 图表测试集

这里有 23 类图表，每类一篇，避免单篇图片缓存上限影响验证。

打开后光标在标题上，图表自动在正文渲染。点击图表进入源码，移出图块恢复预览；修改节点名称后移出，确认图表更新。拖窄侧栏或使用宽终端检查清晰度，滚轮检查长图裁切。

Kitty、Sixel、iTerm2 图像协议可显示文字细节；普通终端或不透传图像的 tmux 使用半块像素，文字可能不清晰，仍可进入源码阅读。设置 LINKNOTE_IMAGE_PROTOCOL=off 时只显示图块标题，进入图块查看源码。

使用官方 Mermaid 11.17.2 与 ZenUML 插件在本机渲染；首次需要在项目根目录执行 `npm ci --prefix scripts/mermaid`，本机已配置。网络图标和外部资源不会加载，之后的新类型需要升级引擎。

## 外观设置

点击右上角「设置」或按 Ctrl+,，在「外观」切换整体深浅主题；在「图表与图片」调整 Mermaid 主题、画布背景和字号。默认跟随整体主题，单张图也可在源码中通过 frontmatter 指定主题。
