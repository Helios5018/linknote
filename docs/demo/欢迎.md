# LinkNote · 让想法留在终端

这是一个普通的 Markdown 文件。点击这段文字就能开始编辑，离开段落后它会恢复排版，修改会自动保存。

## 今天想做的事

- [x] 打开一个本地文件夹
- [x] 写下一点 **值得记住的东西**
- [ ] 在左边新建自己的笔记

## 写作时的小工具

用 **粗体** 标记重点，用 *斜体* 留下旁注，也可以写 `行内代码` 和 [Markdown 链接](https://commonmark.org)。

> 文件一直属于你，可以用任何编辑器打开。

```rust
fn main() {
    println!("你好，LinkNote 🌿");
}
```

| 操作 | 快捷键 |
| --- | --- |
| 新建笔记 | 左栏 a |
| 按文件名打开 | Ctrl+P |
| 全文搜索 | Ctrl+P 后 Tab |
| 打开光标处的链接 | F12 |
| 帮助 | F1 |

笔记之间可以互相链接：[[随手记]]。把光标放在链接上按 F12（或 Ctrl+点击）就能打开，Shift+F12 回到这里。

中文、emoji 👨‍👩‍👧‍👦、组合字符 café 都可以直接输入。
