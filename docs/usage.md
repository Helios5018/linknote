# LinkNote 使用手册

本文是 LinkNote 的完整使用说明：启动方式、界面操作、快捷键、设置、保存与恢复、图片、Mermaid 以及当前边界。项目概览见 [README](../README.md)，设计与实验见 [design.md](design.md)。

## 运行

建议使用当前 stable Rust（项目使用 edition 2024）；已在 macOS arm64、Rust 1.98.1 实测。

```sh
cargo build --release --locked
./target/release/linknote               # 默认打开 ~/Note，不存在时自动创建
./target/release/linknote open          # 打开当前目录
./target/release/linknote open ./docs/demo
./target/release/linknote open /你的/笔记.md
```

`docs/demo` 是可编辑的示例笔记。安装使用 `sh scripts/install.sh`：安装到 Cargo bin 目录，并自动创建 `~/Note`。如果直接用 `cargo install --path . --locked`，默认笔记目录会在首次无参数启动时创建。`linknote --help` 查看命令行帮助。

## 命令行用法

安装后（Cargo bin 目录需在 `PATH` 中）可以在任意目录运行：

```sh
linknote                  # 打开 ~/Note
linknote open             # 打开当前目录
linknote open ~/其他笔记   # 打开指定目录
linknote open ./笔记.md    # 打开指定 Markdown 文件
linknote ./笔记.md         # 兼容原有用法：直接传入目录或 Markdown 文件
```

相对路径以启动时的当前目录为基准；打开名为 `open` 的目录请用 `linknote open ./open` 或 `linknote -- open`，以 `-` 开头的路径使用 `./` 前缀或 `--` 分隔。

可选：在 shell 配置（如 `~/.zshrc`）中添加别名，`scripts/install.sh` 结束时也会给出同样的建议：

```sh
alias ln='linknote'
alias lno='linknote open'
```

注意 `ln` 会遮蔽系统的硬链接命令；需要原命令时使用 `command ln` 或 `/bin/ln`，也可以换一个不冲突的别名。

## 界面与编辑

- 左栏递归浏览文件夹，以及 `.md` / `.markdown` 文件（扩展名不区分大小写）。空文件夹也显示；以 `.` 开头的隐藏项、`node_modules` 和符号链接不列出。可在笔记目录放一个 `.linknoteignore`，每行一个名称，支持 `*` / `?` 通配，结尾 `/` 只匹配文件夹，`#` 开头为注释；左栏、Ctrl+P 和全文搜索都会遵守。无权读取的子文件夹按空文件夹处理，不影响其他笔记。
- 鼠标单击文件在右侧打开，同时聚焦左栏；点击左栏空白或标题也会聚焦左栏，边框高亮。按 Enter、双击笔记或点击右侧正文进入编辑；点击段落即定位编辑，支持拖动选区。编辑区滚轮滚动正文，左栏滚轮只滚动列表、不改变选中项。也可以用左栏的方向键、PageUp/PageDown 与 Enter。
- 点击「笔记」标题栏右侧的「<」折叠左栏，点击内容区左上角的「>」恢复；也可按 Ctrl+B 切换（设置中可改快捷键）。收起后正文占满宽度，展开保留原栏宽与目录状态；窄窗口展开时切到笔记列表。
- 按住中间分隔线左右拖动，调整左右栏宽度；也可在「设置 → 外观 → 侧栏宽度」中用左右键调整，每次两列。栏宽按笔记目录记住，重新打开仍保留；左栏至少 20 列、右栏至少 32 列。终端不足 64 列时仍使用单栏切换，放大后恢复设置。
- 当前标题、段落、整个列表、引用、代码块或表格显示原始 Markdown。离开该块后恢复排版；跨块选择时涉及的块一起展开。
- 表格编辑时保留 `|`、`**` 等源码符号，同时保留外框和行间横线，使用虚拟空白保持列对齐；长单元格按列换行，不把补齐空格或横线写进文件。上下移动光标会跳过装饰横线。
- 表格按终端显示宽度对齐，带边框，表头和每条数据记录之间都有横向分隔线；同一单元格换行时保持在同一格内。支持 Markdown 的左/中/右对齐；列数太多则按记录纵向排列，保留全部内容。点击单元格可直接回到对应源码。
- 无序列表按层级显示 `•` / `◦` / `▪` 并缩进；连续嵌套的有序列表显示 `1.` / `1.1.` / `1.1.1.`。换行后对齐正文，显示层级不改写文件中的标记。在列表项上按 Tab 会把它缩进到上一项之下，Shift+Tab 退回上一级；空的子项按 Enter 先回到上一级，空的顶层项再按 Enter 结束列表。
- 中文、emoji、组合字符按字素簇移动和删除；长行自动折行。Ctrl/Alt+←/→ 按词移动：中文没有空格，按标点、空白和文字类型（汉字、字母数字、符号）分段，不会一下跳到段尾。Alt+Backspace 删除前一个词。兼容 `**采取行动：**正文` 这类中文标点加粗，使用亮暖白色 `#F2EFE2` 强调，同时保留标准终端粗体（SGR 1）。HTML 显示源码，不执行。
- 链接：`[文字](其他笔记.md#标题)`、`[[笔记名]]` / `[[笔记名|显示文字]]`、`#标题` 以及普通网址都可以打开。光标放在链接上按 F12，或按住 Ctrl 点击；Shift+F12 回到跳转前的位置。`[[笔记名]]` 先找当前文件夹和根目录，再在整个目录中找同名笔记；目标笔记不存在时会弹出新建框。网址和非 Markdown 文件交给系统程序打开；指向笔记目录之外的路径不会打开。
- 右侧标题只显示文件名。图片在正文内显示，点击图片可展开对应的 Markdown 引用。
- 输入后自动保存，切换文件与正常退出也会写回。恢复上次文件和光标位置。界面底部只有一行状态栏：保存状态、行列、编码，以及最近几秒的提示。

### 新建与焦点

1. 单击左栏（文件、空白或标题均可），或按 Ctrl+W / Esc 从编辑器切换过去；Esc 有选区时先清除选区。
2. 按 `a` 即可打开新建框，不需要 Shift；`Shift+A` 也支持。在右侧输入 `a` / `A` 仍然是编辑正文。
3. 输入 `想法` 创建 `想法.md`；输入 `资料/` 创建文件夹。已有 `.md` / `.markdown` 后缀保留，大小写不敏感；`.txt`、`.json` 等后缀会提示修改，不生成文件。
4. Enter 确认，Esc 取消。选中文件夹时创建在该文件夹内；选中笔记时创建在笔记所在目录；空列表创建在根目录。紧凑输入框在标题显示目标位置，只保留名称输入和 `.md 笔记 · / 文件夹` 提示；同名项不会覆盖。

新笔记创建后进入右侧编辑；新文件夹创建后留在左侧并选中它，可连续创建其中的笔记。左栏单击目录仍可展开/折叠，滚轮只滚动列表；Enter / 双击笔记进入右侧，Tab / Esc 返回当前编辑器。收起按钮及分隔线拖动仍执行各自功能。

默认键按面板分工：左栏用 `a/r/c/d/m`，正文保留常见编辑组合键。Ctrl+N、Ctrl+Shift+N、左栏 Delete、Ctrl+O 和 F2–F9 不再默认绑定；对应动作仍可在设置的快捷键页自行绑定。Shift+A / Shift+D 和 macOS 的 Command/Ctrl 编辑兼容键保留。

### 保存、设置与退出

| 快捷键 | 功能 |
| --- | --- |
| Ctrl+S | 立即保存（平时自动保存，这个键只为习惯保留） |
| Ctrl+R | 处理保存冲突/失败，或重试保存 |
| Ctrl+, | 打开设置 |
| F1 | 帮助（列出当前生效的快捷键，↑↓ 滚动） |
| Ctrl+Q | 保存后退出 |

文内查找使用智能大小写：查找内容全是小写时不区分大小写，含大写字母时区分。查找框会预填上次的内容并显示为选中，直接输入即替换。正文以及新建、重命名、打开、搜索、查找/替换框均支持全选、复制、剪切、粘贴和独立撤销/重做。输入框支持左右/Home/End 移动、Shift 选区、按词移动和删除；Ctrl+A 是全选，Ctrl+U 保留清空功能，Enter 确定。查找与替换各自保留编辑历史，输入框撤销不会修改正文。系统剪贴板不可用时保留应用内剪贴板；终端自带的粘贴快捷键也支持。无系统剪贴板的环境或自动化验证可设置 `LINKNOTE_CLIPBOARD=internal`，只使用应用内剪贴板。

### macOS Command 与终端兼容性

Mac 默认同时接受 Command（⌘）和 Ctrl 的常用编辑快捷键。启动时请求 Kitty 增强键盘协议，退出时恢复；不支持协议的终端继续使用原有 Ctrl 按键。未绑定的 Command 组合不会作为普通字母写入笔记。

Command 按键必须先由终端传给 LinkNote。终端自己的复制、全选或撤销可能先截获 `⌘C`、`⌘A`、`⌘Z`；启用协议不能强制覆盖这些原生动作。`⌘V` 可由终端直接发送粘贴事件，LinkNote 同样接收。部分终端（例如 cmux）的原生复制与全选仍可能拦截 Command：应用侧绑定已支持，但协议层测试不等同于每个终端的实体按键都已生效。遇到冲突时可先用 Ctrl，终端侧转发需单独适配，不要全局把 `⌘C` 映射成 `Ctrl+C`（会影响其他命令的中断行为）。

### 自定义快捷键

在应用配置目录放一个 `keys.json`（macOS 为 `~/Library/Application Support/linknote/keys.json`，可用 `LINKNOTE_CONFIG_DIR` 指定目录）。为某个动作写出的按键会替换它的默认按键，空列表表示取消绑定：

```json
{
  "keys": {
    "search_notes": ["ctrl+o"],
    "back": ["shift+f12", "alt+left"]
  }
}
```

动作名：`create`（仅左栏） `help` `settings` `quit` `save` `new_note` `new_folder` `rename` `rename_tree`（左栏 `r`） `copy_path`（左栏 `c`） `move` `move_tree`（左栏 `m`） `delete` `open_note` `search_notes` `find` `find_next` `follow_link` `back` `switch_focus` `toggle_sidebar` `narrow_sidebar` `widen_sidebar` `reload_images` `load_remote_images` `view_image` `resolve` `undo` `redo` `select_all` `copy` `cut` `paste`。按键写法如 `cmd+c`（也接受 `command` / `super`）、`ctrl+n`、`alt+left`、`shift+f12`、`f4`、`delete`。配置有误时，启动后状态栏会提示具体问题，其余动作照常使用默认值。方向键、Enter、Backspace、Tab 等编辑键不可改。部分终端无法区分 Ctrl+Shift+字母与 Ctrl+字母，这类组合建议改用功能键。

## 设置

点击右上角「设置」，或按 **Ctrl+,**。面板分三类：

| 分类 | 可调整内容 |
| --- | --- |
| 外观 | 整体深色/浅色主题、侧栏显示、当前目录的侧栏宽度 |
| 图表与图片 | Mermaid 默认主题、画布背景、字号、图片自动/字符图/关闭、本篇网络图片许可、重新加载图片 |
| 快捷键 | 查看全部动作、录入新快捷键、恢复某项默认绑定 |

`Tab / Shift+Tab` 切换分类，`↑↓` 选择，`←→ / Enter` 调整；鼠标可点击分类和选项。改动自动保存并立即生效，`Esc` 关闭。快捷键页按 Enter 后直接按新组合键，Esc 取消录入，Backspace 恢复默认；通常接受功能键或 Ctrl/Alt/Cmd 组合；仅左栏动作（如 `create`）也可录入单字母，不影响正文输入。相同作用域或全局绑定冲突时提示，不自动抢占其他动作。

整体主题影响正文、侧栏、查找、帮助和设置弹窗。Mermaid 默认跟随整体主题；单张图源码中的主题配置优先，画布设为「跟随图表主题」时同步变深或变浅，也可选择深色、浅色或透明。字号范围 12–32 px，大图仍按正文宽度缩放。

应用设置写入应用配置目录的 `settings.json`，快捷键保留在 `keys.json`；`LINKNOTE_CONFIG_DIR` 可指定此目录。侧栏宽度和网络图片许可仍按笔记目录/笔记写入 session。配置损坏、写入失败或其他窗口修改时会提示并保留原文件；关闭后重开设置可读取最新配置。自动图片模式沿用终端探测和 `LINKNOTE_IMAGE_PROTOCOL`，字符图/关闭可手动覆盖；若设置了 `LINKNOTE_REMOTE_IMAGES=1`，网络图片许可由该环境配置控制，面板会说明。

## 保存与恢复

- 停止输入 **500ms** 后自动保存；持续输入最长每 **2s** 保存一次。状态栏显示保存中、已保存或错误。
- 在目标目录写临时文件、刷新到磁盘后原子替换，保留原文件权限；只读文件拒绝覆盖。
- 保存前及临时文件写完后检查磁盘版本。检测到外部修改/删除时停止覆盖，按 Ctrl+R 处理：`v` 查看磁盘版本与本地版本的逐行差异；Enter 把本地内容另存为新的 `.local-N.md`，两份都保留；`l` 改用磁盘版本（本地内容留在撤销历史中，Ctrl+Z 可找回）；`o` 明确选择用本地版本覆盖磁盘。
- 有未解决冲突或保存失败的笔记不会把你困住：切换到其他笔记时，它的内容保存在恢复草稿里，左栏在它的文件名后显示 `●`；重新打开它时会提示恢复，再继续处理冲突。
- 无本地改动时，每秒检查并加载外部更新；重新加载可撤销。文件被短暂移走后原样恢复（如切换 Git 分支、同步工具先删后建）时，冲突提示自动解除。目录树每两秒刷新一次。
- 尚未写回的编辑约每 **150ms** 写入应用数据目录中的恢复草稿（超过 512 KiB 的笔记约每秒一次）。草稿只保存当前文本和原文件的指纹，不再额外保存一份原文件。异常退出后再次打开该文件会询问是否恢复。突然断电或强制结束仍可能丢失最近一个草稿周期内的输入。草稿写不进去时状态栏显示警告，但笔记本身照常自动保存；草稿文件损坏时会改名为 `*.corrupt-N.json` 留在原处，笔记按磁盘版本打开。
- 保存失败时不会清空编辑器；Ctrl+R 可另存副本，或按 `q` 在恢复草稿成功写入后退出。
- 同一应用数据目录下的 LinkNote 实例对同一笔记使用排他锁，避免共享恢复草稿；没有草稿时，关闭笔记会删除对应的锁文件。其他编辑器不受此锁约束；检测与替换之间仍存在极短的文件系统竞争窗口，本工具不是多端协同编辑系统。

应用状态不写进笔记目录。macOS 默认保存在 `~/Library/Application Support/linknote/`，其他平台使用系统应用数据目录。可用 `LINKNOTE_STATE_DIR=/自定义路径` 覆盖。`recovery/` 里是恢复草稿与锁文件，根部 `*.session.json` 保存各笔记目录的上次文件、光标位置、栏宽和允许加载网络图片的笔记；已不存在的笔记会在写入时清理掉。

删除默认移到系统废纸篓（macOS 使用系统接口，不需要额外授权）。设置 `LINKNOTE_TRASH_DIR=/某个目录` 时改为移动到该目录。网址等外部链接默认用 `open`（macOS）/ `xdg-open` 打开，可用 `LINKNOTE_OPENER` 指定其他程序。

## 图片

支持相对当前 Markdown 文件的本地路径、绝对路径和 HTTP(S) 地址，以及 PNG、JPEG、WebP、GIF 首帧。例如 `![说明](assets/photo.png)`。加载与编码在后台线程执行，不阻塞打字。缺失或无法解码的图片会显示错误，不影响笔记编辑。

网络图片默认不加载：请求图片会向对方暴露你的 IP 和打开时间，也会触发追踪像素。图片位置显示“网络图片未加载”，在「设置 → 图表与图片 → 本篇网络图片」允许加载，这个选择按笔记记住，也可在那里取消。设置 `LINKNOTE_REMOTE_IMAGES=1` 可始终自动加载。网络图片不使用浏览器登录态。

使用 [ratatui-image](https://github.com/ratatui/ratatui-image) 自动探测 Kitty、Sixel、iTerm2 协议；终端不支持时退回彩色字符图。图像可以随正文滚动、部分露出，调整栏宽后重新适配。环境变量 `LINKNOTE_IMAGE_PROTOCOL=halfblocks` 可强制字符图，`kitty` / `sixel` / `iterm2` 可指定协议，`off` 关闭加载、只显示说明。终端没有回应协议探测时（例如 tmux 未开启 `allow-passthrough`），LinkNote 会补发一次状态查询，避免探测线程吞掉你按下的第一个键。

每篇笔记最多自动加载 16 个不同地址，同时最多两项任务。单张文件上限 12 MiB、解码内存上限 64 MiB，解码后缩略缓存最长边 1200 像素；正文预览最多 96 列 × 18 行。表格单元格里的图片保留文字说明，暂不嵌入图像；SVG、动画和浏览器登录后才能访问的图片暂不支持。

### 全屏查看与放大

点击预览旁的 🔍，或把光标放在图片引用 / Mermaid 源码内按 F10，进入全屏图片查看器。查看器隔离键盘、粘贴和鼠标输入，Esc 关闭后保留笔记光标、选区与滚动位置；查看期间继续自动保存。

- `+` / `-`：缩放，范围为适应窗口的 25%–1600%；`0`：恢复适应窗口并居中。
- 方向键、鼠标拖动和滚轮：平移；Ctrl+滚轮：缩放。到图像边缘会停止平移。
- `O` 或点击底部「系统打开」：普通本地图片交给系统应用；网络图片打开已获许可后下载的本地副本；Mermaid 打开包含 SVG 的本地浏览器页面，可用浏览器缩放继续查看。生成的页面禁止脚本和外部资源请求。
- `Esc` 或点击右上角「关闭」：返回笔记。放大快捷键可在设置中修改，动作名为 `view_image`。

普通图片在查看时按需读取原始分辨率，仍受 12 MiB 文件、8192 像素边长和 64 MiB 解码内存限制。Mermaid 在查看器中保留 SVG，每次缩放和平移只栅格化当前可见区域；视口最多 4096 像素边长、800 万像素。加载和编码在后台执行，连续操作合并到最新位置，旧画面会在新画面准备好后替换，渲染期间可随时 Esc 关闭。关闭图片显示时需先在设置中开启；网络图片沿用设置中的本篇许可。

系统打开用的临时副本在关闭查看器后保留至 LinkNote 退出，随后自动清理；需要长期保存时，请在系统应用中另存。字符图终端仍受字符分辨率限制，细小文字建议用「系统打开」查看。

## Mermaid 图表

标记为 `mermaid` 的围栏代码块会在正文中渲染。点击图表或用方向键进入其所在块时显示源码，移到其他块后恢复图表；修改与撤销直接作用于原 Markdown，自动保存不会改写语法。波浪线围栏、引用和列表里的图块也支持。「设置 → 图表与图片 → 重新加载图片」可重新渲染。

使用官方 **Mermaid 11.17.2** 和 ZenUML 插件，在本机临时无头 Chromium 中生成图像。首次配置需要 **Node.js 22.12+**，在项目根目录执行：

```sh
npm ci --prefix scripts/mermaid
```

这一步会下载 JavaScript 依赖和 Puppeteer 所需浏览器。之后渲染无需联网、不启动服务，页面的外部资源请求被拦截，每次渲染结束关闭浏览器。缺少组件、语法错误或超时时会在图块显示提示，笔记仍可编辑保存。二进制默认从编译时的项目目录查找组件；搬动或分发二进制时，把 `scripts/mermaid` 连同安装好的依赖保留在本机，并设置 `LINKNOTE_MERMAID_DIR=/绝对路径/scripts/mermaid`。不要把 `node_modules` 提交到 Git。

[demo/Mermaid](docs/demo/Mermaid/00-开始.md) 有 23 类图表，每类一篇：流程图、时序图、类图、状态图、ER、饼图、甘特图、用户旅程、Git 分支、思维导图、时间线、XY、象限、桑基、需求、C4、块图、架构、数据包、看板、雷达、矩形树图和 ZenUML。另有异常与边界测试页。

图表复用终端图像协议。Kitty/Sixel/iTerm2 可显示文字细节；普通终端或未透传图像的 tmux 会退回半块像素，文字清晰度有限，可进入源码阅读。在设置中关闭图片，或自动模式下使用 `LINKNOTE_IMAGE_PROTOCOL=off`，只显示图块标题。预览按正文宽度缩放，最多 80 行并随正文滚动。

图片与图表共享每篇 16 个不同来源、同时 2 个任务的缓存；同样的图表源码复用缓存。单图限 32 KiB / 512 行 / 512 条边，正文预览输出不超过 1600 × 2400 像素，单次渲染最长 25 秒。网络图片、外部图标包和外部字体不会在 Mermaid 中加载，图中链接也不会自动打开；本地系统需有相应文字的字体。支持范围以锁定的官方引擎版本为准，不包含后续 Mermaid 版本的新类型。

## 当前边界

- 单文件限 4 MiB，UTF-8 编码；未编辑的文件不重写。CRLF 文件写回仍为 CRLF；混合换行文件第一次编辑后统一为 CRLF。
- 性能（本机发布构建实测）：1 MiB 笔记移动光标约 0.7ms、输入一个字约 10ms；4 MiB 笔记分别约 2.6ms 和 41ms。每次输入仍会完整解析一遍 Markdown，排版只重做变化的块。
- 常见 Markdown 样式、分级列表、引用、代码、对齐表格、图片、Mermaid 和 `[[维基链接]]` 可显示；表格按整块源码编辑。没有数学排版、反向链接列表或同步服务。
- TUI 是等宽终端排版，不能改变标题字号。emoji 最终宽度仍依赖终端；输入法候选窗由终端负责。中文字符输入和粘贴已测试，未逐一测试各输入法与终端组合。
- 粗体请求由终端选择粗体字形。cmux 使用 Ghostty 的字体配置，默认中文回退可能是 PingFang SC；如果文字字重无明显变化，亮色强调仍能区分重点，参见 [Ghostty 字体说明](https://ghostty.org/docs/config/reference#font-family)。LinkNote 不自动改动全局终端字体。
- 撤销按编辑记录，最多 1000 组、约 16 MiB 的改动内容（至少保留最近一步）；大文件也能撤销多步。关闭笔记后不保留撤销历史。
- 文件树最多递归 64 层。当前文件消失时保留内存内容；恢复草稿对应的文件若已经不存在，需要先重建同路径文件，再启动并恢复。
- macOS 已实测；使用跨平台组件，但尚未在 Linux/Windows 做运行验证。
